# Список релізів — LC-MS Screening

Усі версії проекту з коротким описом змін. Хронологія від найновішого.

## Версії

| Версія | Дата | Основні зміни |
|--------|------|----------------|
| [v0.9.0](./v0.9.0.md) | 2026-06-12 | Гнучкість аналізатора: вхідні формати + профілі приладів, робота без Polarity/Base Peak (RT-only), S/B без корзини blank, ширина корзини за сурогатом, термінологія RSD/хроматограма |
| [v0.8.0](./v0.8.0.md) | 2026-04-25 | LabSpaces: persistent workspace для datasets, analyzers та історії звітів |
| [v0.7.1](./v7.1.md) | 2026-04-25 | Стартова версія: blank subtraction до злиття, RT-only режим, surrogate standards |

## Нотатки

- `v0.7.1` — точка відліку. Зміни попередніх версій не документовані.
- Кожна версія описує лише дельту відносно попередньої.
- Актуальна HTML-версія кожного релізу доступна в `app/static/releases/`.
